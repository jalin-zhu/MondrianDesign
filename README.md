# MondrianDesign

MondrianDesign is a React component library inspired by Mondrian color blocks.

## Workspaces

- `packages/mondrian-design`: publishable npm package
- `apps/storybook`: component docs and playground

## Quick Start

```bash
npm install
npm run build
npm run storybook
```

## Release

```bash
npm run changeset
npm run version-packages
npm run release
```
